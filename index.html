01  ·  PENDAHULUAN

Tujuan dan Ruang Lingkup Praktikum

Praktikum ini bertujuan untuk merancang serta menguji komunikasi antar-subnet yang memiliki segmen alamat IP berbeda, memanfaatkan Router sebagai penghubung (gateway) utama serta Switch dan Hub sebagai pembagi jaringan lokal.

Simulasi dijalankan menggunakan Cisco Packet Tracer untuk menganalisis proses transmisi data, khususnya perilaku protokol Layer 2 (Address Resolution Protocol) dan Layer 3 (Internet Control Message Protocol) baik dalam mode pengujian langsung (Realtime) maupun mode penelusuran paket (Simulation).

01
TOPOLOGI

Perancangan Topologi Fisik

4 unit PC, 1 Hub, 1 Switch, dan 1 Router terhubung dengan kabel Copper Straight-Through. PC0 & PC1 ke Hub0, PC2 & PC3 ke Switch0, keduanya bertemu di interface FastEthernet Router2.

02
HARDWARE

Pemasangan Modul Router2

Router dimatikan (power off), lalu modul FastEthernet (PT-ROUTER-NM-1FFE) dipasang manual ke slot sasis yang kosong sebelum daya dinyalakan kembali.

03
KONFIGURASI CLI

Eksekusi Perintah pada Router2

Alamat 192.168.1.3/24 diset pada FastEthernet0/0 dan 192.168.2.3/24 pada FastEthernet1/0, diikuti no shutdown hingga kedua port berstatus up.

04

Konfigurasi PC0

IP 192.168.2.1 / 255.255.255.0, gateway 192.168.2.3 yang terhubung ke interface FastEthernet1/0 Router2.

05
SUBNET A

Konfigurasi PC1

IP 192.168.2.2 / 255.255.255.0, gateway 192.168.2.3, satu segmen dengan PC0 di Subnet A.

06
SUBNET B

Konfigurasi PC2

IP 192.168.1.1 / 255.255.255.0, gateway 192.168.1.3 yang mengarah ke interface FastEthernet0/0 Router2.

07
SUBNET B

Konfigurasi PC3

11  ·  ANALISA ALUR PAKET

Ping PC0 → PC3, langkah demi langkah

0.000s — Inisiasi
PC0 mendeteksi tujuan di luar subnet lokal
Operasi AND antara IP tujuan dan subnet mask menunjukkan PC3 berada di segmen berbeda, sehingga paket ICMP Echo Request diarahkan ke MAC address Default Gateway (FastEthernet1/0 Router2).
0.001s – 0.002s — Layer 1
Hub0 melakukan flooding ke semua port
Hub bekerja sebagai repeater tanpa tabel MAC, memancarkan paket ke semua port. PC1 membuang paket karena MAC tidak cocok, sedangkan Router2 menerimanya.
0.003s — Layer 3
Router2 meneruskan paket antar-segmen
Header IP diperiksa, tabel routing dicocokkan, TTL diturunkan dari 128 ke 127, lalu paket dienkapsulasi ulang dan diteruskan ke Switch0.
0.004s – 0.005s — Layer 2
Switch0 meneruskan secara unicast
MAC Address Table dicek, paket dikirim hanya ke port PC3 tanpa mengganggu PC2, sehingga collision domain terisolasi dengan baik.
0.006s – 0.008s — Balasan
PC3 membalas, paket kembali ke PC0
ICMP Echo Reply mengalir terbalik melewati Switch0, Router2, dan Hub0, hingga diterima utuh oleh PC0 yang mengonfirmasi interkoneksi berhasil.
12  ·  KESIMPULAN

Komunikasi antar-subnet berhasil terhubung

Seluruh PC pada Subnet A dan Subnet B berhasil berkomunikasi lintas segmen melalui Router2, dengan hasil ping dan Simple PDU konsisten Successful dan 0% packet loss. Perilaku ARP, flooding pada Hub, forwarding Layer 3 di Router, dan unicast switching di Switch teramati jelas lewat Simulation Mode.
